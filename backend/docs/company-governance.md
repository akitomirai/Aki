# 企业主体管理设计

企业主体是账号、产品、批次和公开追溯的归属边界。本系统按“平台建档、企业自维护、状态控制业务准入”的方式管理企业。

## 使用角色

| 角色 | 使用目标 | 可操作范围 |
| --- | --- | --- |
| 平台管理员 | 新增入驻企业、维护企业状态、清理未使用企业档案 | 全平台企业档案，可新增、编辑、启用、停用、归档、删除未关联企业 |
| 企业管理员 | 维护本企业联系资料 | 只能查看本企业档案并编辑联系人、电话、地址，不能改企业名称、许可证号、状态，不能新建其他企业 |
| 现场操作员 | 依附企业执行现场作业 | 不进入企业管理模块，企业停用后不能继续登录作业 |
| 监管人员 | 监管追溯与风险 | 不维护企业档案 |

## 企业状态

| 状态 | 含义 | 业务影响 |
| --- | --- | --- |
| 启用中 | 企业处于正常经营和追溯接入状态 | 可开户、可登录、可创建产品和批次 |
| 已停用 | 暂停企业后台和移动端使用 | 企业管理员、现场操作员不能登录；不能新开或迁入企业账号；不能挂载新产品 |
| 已归档 | 企业主体不再参与新业务 | 与停用相同，只保留历史追溯和审计数据 |

## 管理流程

1. 平台管理员先创建企业主体，填写名称、许可证号、联系人、电话和地址。
2. 企业启用后，平台管理员为该企业开通企业管理员账号。
3. 企业管理员维护本企业联系人、联系电话和地址，并为本企业现场操作员开户。
4. 平台停用或归档企业后，企业账号旧 token 会在后续请求中失效，重新登录也会被拒绝。
5. 已关联产品或批次的企业不能物理删除，应使用停用或归档保留历史链路。
