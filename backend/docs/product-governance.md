# 产品档案管理设计

产品档案是批次建档前的基础数据，用来明确“哪个企业、哪个产品、哪个编码和产地”进入追溯链。

## 使用角色

| 角色 | 使用目标 | 可操作范围 |
| --- | --- | --- |
| 平台管理员 | 统一查看和维护全平台产品档案 | 可按企业维护产品，可启用、停用、归档、删除未关联批次的产品 |
| 企业管理员 | 维护本企业可追溯产品 | 只能查看和维护本企业产品，不能挂到其他企业 |
| 现场操作员 | 执行被分配批次作业 | 不维护产品档案，只读取批次关联的产品信息 |
| 监管人员 | 监管追溯结果 | 不维护产品档案 |

## 产品状态

| 状态 | 含义 | 业务影响 |
| --- | --- | --- |
| 启用中 | 产品可继续进入追溯业务 | 可出现在批次建档产品选项中，可创建新批次 |
| 已停用 | 暂停新批次使用 | 不出现在批次建档产品选项中，直接提交产品 ID 创建批次也会被拒绝 |
| 已归档 | 产品不再参与新业务 | 与停用相同，仅保留历史批次和公开追溯链路 |

## 管理流程

1. 平台管理员或企业管理员先在产品档案中维护产品名称、产品编码、分类、产地、规格和单位。
2. 企业管理员只能维护本企业产品，平台管理员可跨企业维护。
3. 同一企业下允许维护同名产品，但必须填写不同的产品编码；未填写编码的同名产品会被拒绝，避免建批次时选错。
4. 企业停用或归档后，不能继续新增或改挂产品到该企业。
5. 产品停用或归档后，不能继续创建新批次；历史批次继续保留。
6. 已关联批次的产品不能物理删除，应通过停用或归档阻断新业务。
