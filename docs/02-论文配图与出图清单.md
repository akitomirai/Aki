# 论文配图与出图清单（第2包）

## 1. 配图总原则

论文配图的目标不是展示页面好不好看，而是帮助老师快速理解系统的设计依据、业务闭环、数据关系和实现边界。每张图都应服务于论文正文中的某一类论证：系统为什么这样拆分、角色如何协作、批次如何贯穿业务、数据库如何支撑流程、风险状态如何被约束。

当前实现和扩展设计必须分开绘制。论文主图优先依据当前真实实现，包括 `docs/01-论文基础材料.md`、`backend/src/main/resources/schema-demo.sql`、后端 controller、管理端 router 和公开端 router。`docs/database/sql/01_schema.sql` 中的更完整 MySQL 结构只能作为“扩展参考”单独说明，不能混入当前实现的主 ER 图。

图名口径统一使用“溯源”。例如论文中建议使用“农产品溯源管理信息系统总体架构图”“业务溯源主流程图”等名称；涉及项目已有页面或接口命名时，可以保留“公开追溯查询”“公开追溯端”等本地实现表述。
