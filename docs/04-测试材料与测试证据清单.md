# 测试材料与测试证据清单（第4包）

## 1. 测试材料总原则

测试材料需要区分“已有测试线索”和“论文可直接使用的测试证据”。已有测试线索包括 e2e 脚本、后端集成测试、测试夹具、路由权限控制、controller 接口和基线文档；论文可直接使用的测试证据还需要补充实际运行时间、运行命令、运行结果、截图、接口返回或日志记录。

demo 演示流程和 test fixture 需要分开表述。当前主演示链路应采用 demo profile 中的固定数据：主演示批次 `ORANGE-202603-D1`，主 token `orange-202603-d1`。`test-token-2026` 只能作为后端测试夹具或历史冲突说明，不能写成当前主演示测试对象。

论文测试章节建议按“功能测试、主链路闭环测试、异常测试、权限测试、测试结果汇总”分层组织。功能测试证明各模块可用，主链路测试证明业务闭环成立，异常测试证明边界处理，权限测试证明角色访问控制，测试结果汇总用于展示整体通过情况和遗留风险。
