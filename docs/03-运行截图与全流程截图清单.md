# 运行截图与全流程截图清单（第3包）

## 1. 截图总原则

运行截图用于支撑毕业论文中的“系统实现”“功能展示”“运行结果”和“答辩演示”部分。截图应证明系统确实具备登录、角色入口、企业与产品建档、批次管理、现场填报、质检、二维码发布、公开查询、风险处理和监管查看等能力，而不是用于产品宣传或界面美化展示。

截图必须与当前本地实现一致。后台截图优先依据 `admin-web/src/pages`、`admin-web/src/router/index.js` 和后端 controller；公开端截图优先依据 `trace-web/src/views/TraceDetailView.vue`、`trace-web/src/router/index.js` 和 `PublicTraceController`。截图中的演示数据应优先采用当前 demo profile 中真实存在的数据。

主演示数据统一口径如下：主演示批次采用 `ORANGE-202603-D1`，主公开 token 采用 `orange-202603-d1`，主演示企业为 `赣南果业种植有限公司`，主演示产品为 `赣南脐橙`。后台账号优先使用 `platform / 123456` 展示全局链路，必要时切换 `enterprise_admin / 123456`、`operator / 123456` 和 `regulator / 123456` 展示角色差异。

`test-token-2026` 不能进入主演示截图。该 token 属于旧演示文档或测试夹具线索，不是当前主演示链路的主 token。若论文需要说明历史冲突，可在文字中说明，不建议把它作为主流程截图对象。

## 4. 全流程截图顺序

主演示链路建议固定为以下顺序，截图时优先围绕 `ORANGE-202603-D1` 和 `orange-202603-d1` 展开：

1. `05-登录页.png`：打开后台登录页，展示系统入口。

3. `20-企业主体管理.png`：进入企业主体管理，展示主演示企业 `赣南果业种植有限公司` 或企业建档字段。
4. `30-产品建档.png`：进入产品建档，展示主演示产品 `赣南脐橙`。
5. `41-批次创建或编辑.png`：展示批次创建或编辑表单，说明批次与产品、企业的关系。
6. `40-批次列表.png`：回到批次列表，展示 `ORANGE-202603-D1` 在列表中的状态。
7. `50-批次工作台-总览.png`：进入 `/batches/2`，展示主演示批次工作台总览。
8. `51-批次工作台-质检与二维码.png`：在批次工作台展示质检、二维码和公开状态相关区域。
