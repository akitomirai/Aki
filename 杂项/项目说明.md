# 农产品溯源管理信息系统

## 目录说明

- admin-web：后台管理端前端代码，基于 Vue 3 + Vite 实现
- trace-web：公开追溯查询端代码，面向扫码查询和移动端展示场景
- backend：后端服务代码，基于 Spring Boot 实现
- 杂项/启动关闭脚本：本地启动、关闭和辅助脚本
- 杂项/截图：系统运行截图
- 杂项/日志：系统运行日志或测试输出

## 启动方式

在项目根目录执行：

powershell -ExecutionPolicy Bypass -File ".\杂项\启动关闭脚本\start-all.ps1"

## 关闭方式

powershell -ExecutionPolicy Bypass -File ".\杂项\启动关闭脚本\stop-all.ps1"

- 后端健康检查：http://127.0.0.1:8080/actuator/health
- 后台管理端：http://127.0.0.1:5174
